# Foundations

The bedrock of mathematical thinking: logic, sets, proof techniques, and functions.

## Learning Resources

- **[Mathematical Thinking: Problem-Solving and Proofs](../books/mathematical-thinking/)** — current textbook covering these foundations

## Topics

- **Logic** — propositions, quantifiers, logical connectives
- **Set Theory** — sets, operations, relations
- **Proof Techniques** — direct proof, contradiction, contrapositive, induction
- **Functions** — injections, surjections, bijections, composition
